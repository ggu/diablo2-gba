# Source snapshot provenance

This Diablo II-only source repository was exported from the authored Diablo II and shared GBA files in the local `blizzard-gba` workspace at snapshot commit `d802ac597cca9a294834d19a815f03616af6ca22` (2026-10-22).

The export has a fresh, source-only Git history. It excludes the StarCraft project, private inputs, commercial game ROMs, demo archives, extracted or converted game assets, generated headers, compiled ROMs, screenshots, save files, emulator reports, and machine-specific configuration. The default original-art profile is independently buildable without game data. The optional Den profile prepares its inputs locally and is not a source distribution of the demo or its contents.

The public source URL is [github.com/ggu/diablo2-gba](https://github.com/ggu/diablo2-gba). Pinned reference revisions, licenses, and source locations are recorded in [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md) and [docs/D2-DEN.md](docs/D2-DEN.md). Third-party code and content retain their own licenses.
